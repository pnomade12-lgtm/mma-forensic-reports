우리 시스템의 강점

UFC 외 단체 (BC · Road FC · ONE · Bellator) 의 영상으로도 같은 22 항목 출력 가능합니다. 우주박사 시스템은 UFC 공식 통계가 있는 경기에만 의존하지만, 우리는 영상 자체에서 자동 검출하기 때문에 영상만 있으면 어떤 단체도 분석 가능. 한국 시장 (블랙컴뱃 · Road FC) 의 사업 기회는 우리만 잡을 수 있습니다.

또한 코치·매치메이커·선수 본인이 받아 보는 인사이트 layer (셋업 패턴 · 콤비 분석 · 약점 입구) 는 단순 통계 카운트가 아닌 forensic 영역이고, UFC 공식 통계도 이걸 안 제공합니다.

우주박사 시스템에서 가져올 가치

1. ufcscraper 인프라 — UFC 모든 역대 경기 자료를 한 번에 자동 수집 가능합니다. 우리 자체 미니 scraper 를 일일이 만드는 대신 그의 라이브러리를 가져오면 시간 대폭 절약. 단 라이센스 협의 필요.

2. BestFightOdds 통합 — 베팅 오즈 자료를 22 항목 옆에 같이 표시하면 매치메이커·도박사용 보고서로 영역 확장 가능합니다.

3. ufcpredictor 예측 layer — 우리 22 항목 + forensic 인사이트 + 예측 60~64% 정확도까지 통합되면 코치진뿐 아니라 도박 시장도 동시 사로잡을 수 있습니다.

4. 데이터 스키마 표준 — 4 테이블 (Event · Fight · Fighter · Round) 구조를 우리도 동일 적용하면 두 시스템 자료 호환 가능. 우리 자체 영상 검출 결과도 같은 스키마로 출력하면 ufcpredictor 같은 외부 도구가 우리 자료를 그대로 입력 받을 수 있습니다.

통합 전략 (1 단계 카피캣 이후)

이메일 발송 후 César 의 응답에 따라 협업 경로가 갈립니다.

협업 응답 시 — ufcscraper 라이센스 합의 + 우리 영상 검출 결과를 그의 스키마로 출력 + 두 시스템 자료 결합 (ufcstats 자료 + 우리 영상 검출 자료 + BestFightOdds + 예측). 통합 보고서가 산업 최강 자료 set 이 됩니다.

응답 없거나 협업 거부 시 — 우리 자체 scraper 유지 + 영상 검출 영역으로만 차별화. 그의 ML 예측 모델은 공개 demo (Hugging Face) 를 우리 보고서에 외부 link 로 연결하는 정도. 우리만의 별도 예측 모델 자체 개발은 사업 우선순위에 따라.
